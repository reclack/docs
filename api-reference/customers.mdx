## Create a customer

```http
POST /v1/customers
```

Permission: `customers:write`

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `email` | string | Yes | Where receipts and invoices go. |
| `name` | string | No | Shown on documents. |
| `external_id` | string | No | Your own identifier for this person. |
| `metadata` | object | No | Your own key and value pairs. |

```bash
curl -X POST "https://api.reclack.com/v1/customers" \
  -H "Authorization: Bearer $RECLACK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "dana@acme.dev",
    "name": "Dana Okafor",
    "external_id": "user_4821"
  }'
```

```json 201 Created
{
  "data": {
    "id": "cus_7Fh2PqX9",
    "email": "dana@acme.dev",
    "name": "Dana Okafor",
    "external_id": "user_4821",
    "metadata": {},
    "created_at": "2026-10-18T22:07:41Z",
    "updated_at": "2026-10-18T22:07:41Z"
  }
}
```

<Note>
Creating a customer is not idempotent. Check by `external_id` before creating
if your service might retry. See [Idempotency](/idempotency).
</Note>

## List customers

```http
GET /v1/customers
```

Permission: `customers:read`

| Query parameter | Notes |
| --- | --- |
| `email` | Filter by email address. |
| `external_id` | Filter by your own identifier. |

```bash
curl "https://api.reclack.com/v1/customers?external_id=user_4821" \
  -H "Authorization: Bearer $RECLACK_KEY"
```

## Retrieve a customer

```http
GET /v1/customers/{customerId}
```

Permission: `customers:read`

Returns the customer with its metadata. Subscriptions, invoices and payments
for this customer are read from their own endpoints.
