---
title: "Settlement accounts"
description: "The addresses your payments land in."
---

One address per network you accept. The address belongs to you at all times,
and Reclack never holds a balance between you and your customer. See
[Settlement](/guides/settlement).

## Add an account

```http
POST /v1/merchants/{merchantId}/settlement-accounts
```

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `network` | string | Yes | Lowercase network name, such as `base`. |
| `address` | string | Yes | The address payments on that network settle to. |
| `label` | string | No | For your own reference, such as `Treasury`. |

```bash
curl -X POST "https://api.reclack.com/v1/merchants/mer_2Pb8/settlement-accounts" \
  -H "Authorization: Bearer $RECLACK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "network": "base",
    "address": "0x71B9a0C4f3b1d8e2A5c7E9f0B4d6A8c2E1f34921",
    "label": "Settlement"
  }'
```

<Warning>
Verify the address before you save it. Funds sent to an address you do not
control cannot be recovered by Reclack or by the network.
</Warning>

## List accounts

```http
GET /v1/merchants/{merchantId}/settlement-accounts
```

## Retrieve an account

```http
GET /v1/merchants/{merchantId}/settlement-accounts/{accountId}
```

## Update an account

```http
PATCH /v1/merchants/{merchantId}/settlement-accounts/{accountId}
```

| Parameter | Notes |
| --- | --- |
| `address` | Where future payments on this network settle. |
| `label` | Your own name for it. |

Changing an address affects future payments only. Nothing already settled
moves, and nothing you have already sold changes.

## Balances

```http
GET /v1/merchants/{merchantId}/settlement-balances
```

What has settled, per network. The authoritative record is the chain itself,
and every transaction carries its hash so you can check.
