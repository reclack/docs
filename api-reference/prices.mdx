---
title: "Prices"
description: "The terms a product is sold on."
---

A price belongs to one product and carries the amount, the cadence and the
networks it can settle on. A product can have as many as you need.

## Create a price

```http
POST /v1/products/{productId}/prices
```

Permission: `products:write`

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `amount` | string | Yes | Decimal string, such as `"29.00"`. |
| `cadence` | string | Yes | `once`, `daily`, `weekly`, `monthly` or `yearly`. |
| `networks` | array | No | Networks this price may settle on, such as `["base", "ethereum"]`. |
| `network` | string | No | A single network, when there is only one. |
| `interval_seconds` | integer | No | A custom interval, when the cadences do not fit. |
| `metadata` | object | No | Your own key and value pairs. |

```bash
curl -X POST "https://api.reclack.com/v1/products/prod_2Pb8xk9/prices" \
  -H "Authorization: Bearer $RECLACK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": "290.00",
    "cadence": "yearly",
    "networks": ["base", "ethereum"]
  }'
```

## List prices

```http
GET /v1/products/{productId}/prices
```

Permission: `products:read`

## Retrieve a price

```http
GET /v1/products/{productId}/prices/{priceId}
```

Permission: `products:read`

## Update a price

```http
PATCH /v1/products/{productId}/prices/{priceId}
```

Permission: `products:write`

| Parameter | Type | Notes |
| --- | --- | --- |
| `active` | boolean | An inactive price cannot start new subscriptions. Running ones are untouched. |
| `metadata` | object | Replaces the stored object. |

<Warning>
Changing what you charge is usually a new price rather than an edit. Existing
subscriptions were approved against the terms their customers signed for.
</Warning>

## Delete a price

```http
DELETE /v1/products/{productId}/prices/{priceId}
```

Permission: `products:write`

Deleting is for prices that were never used. Deactivate the rest.
