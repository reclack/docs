A product is the thing you sell. Prices hang off it and carry the terms. See
[Products and prices](/guides/products-and-prices) for how to model them.

## Create a product

```http
POST /v1/products
```

Permission: `products:write`

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | string | Yes | What the product is called. |
| `description` | string | No | Shown on the hosted page. |
| `price` | object | No | Creates a first price in the same call. Fields as in [Create a price](/api-reference/prices#create-a-price). |
| `metadata` | object | No | Your own key and value pairs. |

```bash
curl -X POST "https://api.reclack.com/v1/products" \
  -H "Authorization: Bearer $RECLACK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Pro Plan",
    "description": "Everything in Starter, plus priority support",
    "price": { "amount": "29.00", "cadence": "monthly", "networks": ["base"] }
  }'
```

## List products

```http
GET /v1/products
```

Permission: `products:read`

Returns every product in the environment the key belongs to, each with its
prices.

```bash
curl "https://api.reclack.com/v1/products" \
  -H "Authorization: Bearer $RECLACK_KEY"
```

## Retrieve a product

```http
GET /v1/products/{productId}
```

Permission: `products:read`

## Update a product

```http
PATCH /v1/products/{productId}
```

Permission: `products:write`

| Parameter | Type | Notes |
| --- | --- | --- |
| `name` | string | |
| `description` | string | |
| `active` | boolean | An inactive product cannot start new subscriptions. |
| `metadata` | object | Replaces the stored object. |

```bash
curl -X PATCH "https://api.reclack.com/v1/products/prod_2Pb8xk9" \
  -H "Authorization: Bearer $RECLACK_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "active": false }'
```

## Delete a product

```http
DELETE /v1/products/{productId}
```

Permission: `products:write`

Only a product with no history can be deleted, which the `deletable` field
tells you in advance. Anything that has been sold is deactivated instead, so
your reporting keeps working.
